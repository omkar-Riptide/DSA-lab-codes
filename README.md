## 🚀 Getting Started

### Prerequisites

Depending on the language used in the programs:

- **C / C++**: gcc or g++ compiler
- **Java**: JDK 11+
- **Python**: Python 3.x

### Compiling and Running

#### C / C++

```bash
# Compile
g++ -o main program.cpp

# Run
./main
```

#### Java

```bash
# Compile
javac Program.java

# Run
java Program
```

#### Python

```bash
python program.py
```

## 📝 Coding Guidelines

To keep everything consistent and readable, follow these best practices when adding new content:

1. **Use descriptive filenames**: Keep names clear and consistent, like binary-search-tree.cpp.
2. **Add helpful comments**: Start each program with a short problem description.
3. **Document complexity**: Include time and space complexity wherever relevant.
4. **Provide sample test cases**: Add simple input/output examples in comments when possible.
